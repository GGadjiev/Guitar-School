# Guitar School Landing Page

Учебный проект лендинга репетитора по игре на гитаре. Это мой второй проект, на котором я завершаю изучение HTML и CSS и впервые начинаю использовать SCSS на практике.

## Цель проекта
Закрепить навыки вёрстки и познакомиться с SCSS — препроцессором, который упрощает написание и поддержку стилей.

## Технологии
* **HTML5**: семантическая разметка (`<section>`, `<header>`, `<nav>`, `<footer>`), BEM-методология.
* **CSS3**: Flexbox, абсолютное позиционирование, трансформации, градиенты, тени.
* **SCSS**: переменные для цветов, вложенность (`&`), подключение шрифтов через `@font-face`.
* **Normalize.css + Reset.css**: сброс стилей браузера.
* **Font Awesome**: иконки социальных сетей.

## Чему я научился
* Использовать SCSS-переменные и вложенность для организации стилей.
* Настраивать автокомпиляцию SCSS в CSS через npm-скрипт (`sass --watch`).
* Строить макет с помощью Flexbox и абсолютного позиционирования.
* Работать с CSS-трансформациями и градиентами для декоративных элементов.
* Подключать локальные шрифты через `@font-face`.

## Текущее состояние
* **Адаптивность**: страница оптимизирована только под десктопные экраны.
* **Код**: код не претендует на идеальность, но отражает мой прогресс — переход от чистого CSS к использованию препроцессора.
