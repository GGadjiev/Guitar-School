# Guitar School — лендинг репетитора по игре на гитаре

Учебный проект: одностраничный сайт-визитка преподавателя игры на гитаре. Это мой второй учебный проект — на нём я завершаю изучение HTML и CSS и впервые применяю на практике препроцессор SCSS.

**Демо:** https://ggadjiev.github.io/Guitar-School/

![Скриншот главной страницы](/screenshots/screenshot-full.png)

## Что на странице

- **Шапка** — логотип и меню («Обо мне», «Занятия», «Запись») с переходами к секциям страницы.
- **Главная секция** — фото преподавателя на фоне трёх повёрнутых цветных плашек, заголовок «Я Виктор», подпись «Репетитор игры на гитаре с семилетним опытом преподавания», кнопка «Забронировать урок», блок «Есть вопросы?» и иконки соцсетей (Skype, VK, Telegram, Instagram).
- **Секция «Преподаю»** — карточки направлений обучения (электрогитара, акустическая гитара, укулеле) и статистика: 7 лет преподавания, 276 отзывов на 5 звёзд, 314 обученных студентов, 2000 часов занятий.
- **Секция «Обучение»** — заголовок «Готовлю виртуозов», описание подхода и повторная кнопка записи на урок.
- **Футер** — призыв «Запишись на пробный урок» и иконки соцсетей.
- **Декор** — градиентные круги и повёрнутые фигуры, отрисованные чистым CSS без единой картинки.

## Технологии

- **HTML5** — семантические теги (`<section>`, `<header>`, `<nav>`, `<footer>`), разметка по БЭМ.
- **CSS3** — Flexbox, абсолютное позиционирование, `z-index`, `transform: rotate()`, линейные градиенты, тени, скругления.
- **SCSS** — переменные цветов (`$specific-blue`, `$specific-orange`, `$specific-grey`), вложенность селекторов, модификаторы через амперсанд (`&__item`, `&_big`).
- **Normalize.css + Reset.css** — приведение дефолтных стилей браузеров к единому виду.
- **Шрифты Montserrat** — Light, Regular и SemiBold подключены локально через `@font-face` в форматах `woff2` и `woff`.
- **Font Awesome** — иконки социальных сетей (подключение через CDN-кит).
- **GitHub Actions + GitHub Pages** — автодеплой папки `src/` при каждом пуше в ветку `master`.

## Чему я научился

- Организовывать стили препроцессором: выносить повторяющиеся цвета в переменные, группировать селекторы блоков вложенностью и собирать БЭМ-модификаторы амперсандом.
- Настраивать сборку через npm-скрипт: `sass src/scss:src/css --watch` пересобирает CSS при каждом сохранении исходника.
- Строить раскладку на Flexbox и абсолютном позиционировании: навигация, карточки и списки — на флексах; наложение фото, плашек и кругов — через `position: absolute` и `z-index`.
- Рисовать декоративную графику средствами CSS: повёрнутые плашки (`transform: rotate`), круги с градиентной «обводкой» из двух вложенных элементов, тени и скругления.
- Подключать локальные шрифты в двух форматах и собирать полный набор фавиконок под все платформы (Apple, Android, Windows + `manifest.json`).
- Настраивать автоматический деплой статического сайта на GitHub Pages через GitHub Actions.

## Структура проекта

```text
src/
├── index.html          # разметка страницы
├── css/
│   ├── style.css       # скомпилирован из SCSS — руками не редактируется
│   ├── normalize.css   # нормализация стилей браузеров
│   └── reset.css       # сброс дефолтных стилей
├── scss/
│   └── style.scss      # исходник стилей — все правки вносятся здесь
├── fonts/              # Montserrat Light / Regular / SemiBold (woff, woff2)
├── img/                # фото, логотип и иконки секций
└── icons/favicons/     # фавиконки всех размеров, manifest.json, browserconfig.xml
```

В корне репозитория лежат `package.json` со скриптом компиляции SCSS и `.github/workflows/static.yml` — workflow деплоя на GitHub Pages.

## Запуск локально

Страница полностью статическая: `index.html` подключает уже скомпилированный `css/style.css`, поэтому для просмотра достаточно открыть `src/index.html` в браузере — сборка не требуется.

Компилятор нужен только для правки стилей:

```bash
git clone https://github.com/GGadjiev/Guitar-School.git
cd Guitar-School
npm install     # установит sass (dev-зависимость)
npm run sass    # компиляция src/scss → src/css в режиме --watch
```

После запуска `npm run sass` изменения в `src/scss/style.scss` автоматически пересобираются в `src/css/style.css`.
